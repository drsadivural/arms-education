# 要件

## 製品
名称 ARMS。UI・メール・通知・音声・エラーメッセージは日本語。日付表示 Asia/Tokyo、保存 timestamptz、日付のみの終了予定日は date。既存画面の2019年データは移行時にそのまま保持する。画面見本は2026年の架空データ。

## Webメニュー — 順番固定
1. ダッシュボード（Dashboardの日本語表示）
2. 講師管理
3. 新入社員管理
4. クラスルーム管理
5. 教育プログラム管理
6. 社員教育進捗管理
7. オンライン予約システム
8. 設定

ログ・イベント、ユーザー管理、データ移植、システム設定は「設定」内タブに置く。Webのトップレベルメニューを追加しない。

## ロール
|役割|Web|iOS|範囲|
|---|---|---|---|
|管理者 admin|全機能・承認・移行・設定|対象外、管理はWebへ案内|所属組織|
|講師 teacher|ダッシュボード、担当受講者、担当授業・教材・進捗、担当予約判断|担当授業・担当者進捗・予約確認・出欠・評価・音声|担当クラスまたは担当授業|
|受講者 student|管理メニュー不可|今日の授業・自分の進捗・教材・予約申請/確認/取消・音声|本人|

ロール切替UIは権限を付与しない。ユーザー選択した「受講者/講師」とサーバーmembershipを照合する。不一致は「このアカウントでは選択した利用区分にログインできません」。無効ユーザーはJWT未失効でもAPI拒否。講師の担当外受講者閲覧は403。

## 機能要件
講師: 氏名・ふりがな・メール・所属・専門分野・稼働時間・担当クラス・状態。追加は招待メールとプロフィール作成を分け、メール失敗は再送可能な状態で表示。
新入社員: 社員番号・氏名・ふりがな・会社/部署・入社日・メール・所属クラス・担当講師・研修開始/終了予定日・状態。クラス選択時にそのクラスに紐づく有効講師のみ候補に表示する。
クラス: 名称・年度/期・定員・期間・主担当講師・補助講師・プログラム。人数は在籍の有効受講者をDB集計する。保存した人数を表示しない。定員超過、同時追加、在籍者がいるクラス削除を防止する。
教育プログラム: 名称・説明・対象部署・バージョン・単元・順番・配点/重み・必須フラグ・期限・合格点・公開状態。教材PDF/動画/画像/外部HTTPSリンク、確認テスト、課題、講師承認。公開済み教材の更新は新バージョン。過去進捗を勝手に変更しない。
進捗: 月/部署/講師/クラス/状態/氏名検索、期限超過、詳細履歴、記録追加・編集・コメント・CSV/PDF出力。スクリーンショット由来の列を保持。
予約: 研修・面談の空き枠、申請、承認、理由つき却下、取消、削除（履歴保持）、承認履歴、定員・重複時間制約、メール/APNs/アプリ通知。
設定: 組織名・ロゴ・テーマ・休日・営業時間・予約締切/取消期限・承認保持期限・通知・AI音声使用上限・ユーザー招待/停止・移行・監査ログ・エクスポート。

## 非機能の受入目標（測定して満たすこと）
初期規模 受講者1,000、講師100、同時利用100。API読み取りp95 500ms以内・予約変更p95 1秒以内（外部通知を待たない、同一リージョン想定）。Web初回操作可能3秒以内、一覧100件ずつカーソルページング。予約可視化5秒以内を目標とし、フォーカス時再取得と前景5秒ポーリングで整合する。100同時の残席1申請で成功1件・超過0件。
WCAG 2.2 AAを目標にラベル、キーボード、色以外の状態、コントラストを確認。iOS Dynamic Type、VoiceOver、44ptタップ。レスポンシブ・ライト/ダーク・読み込み/空/エラー/オフライン状態。音声を使わなくても全主要業務ができる。
